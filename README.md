# Hi, I'm Sumit 👋

AI/ML Engineer, FAST-NUCES graduated, building systems at the intersection of **LLMs, retrieval, generative models, and automation**. I like taking a model from a paper or a Colab notebook to something that actually runs, end to end.

---

## ⚙️ What I Build

- **Agentic & automation systems** — LLM-driven pipelines wired into real tools (n8n, Vapi, FastAPI)
- **Retrieval-augmented systems** — domain-specific RAG over structured/unstructured data (clinical records, documents)
- **Generative models** — GANs, diffusion models, image-to-image translation
- **Fine-tuning & adaptation** — LoRA/QLoRA on LLMs and VLMs for narrow, high-value tasks
- **Computer vision** — image captioning, self-supervised pretraining

---

## 🚀 Currently Building

**AI Job Application Automation** — an n8n-based pipeline that sources roles, deduplicates them, matches against my profile, tailors resumes, and tracks everything in Sheets/Postgres.
